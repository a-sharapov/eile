# Изменения

Заметные изменения по версиям. Формат близок к [Keep a Changelog](https://keepachangelog.com/ru/);
проект следует [семантическому версионированию](https://semver.org/lang/ru/) и до `1.0` может
менять поведение между минорными версиями. Полные заметки к релизам — на
[странице релизов](https://github.com/a-sharapov/eile/releases).

## [0.1.6] — 2026-11-09

### Адреса в стиле Evo (ADR 0063)

- Стиль адресов сайта — в настройках: окончание документа (`urlSuffix`: пусто, `/` или `.html`) и «папки со
  слэшем» (`folderSlash`). По умолчанию адреса прежние, без окончаний. Меняет только человек в менеджере.
- У страницы флаги «Папка» (`folder`) и «Алиас в адресах дочерних» (`aliasInPath`), как `isfolder` и
  `alias_visible` в Evo. Страница с дочерней становится папкой сама; её прежний адрес ведёт 301 на новый.
- Канонический адрес — 200, его варианты (без суффикса, с лишним `/`, без `/` у папки) — 301; прежние адреса
  и правила переадресации находятся с любым окончанием.
- Адрес с окончанием — везде: `link()`, `[~id~]`, canonical, Open Graph, JSON-LD, sitemap.xml, llms.txt,
  поиск, предпросмотр, диагностика ссылок, «Открыть на сайте». Markdown-версия — `/katalog.md`.
- Порции списка: `/katalog/page-2/` у папки, `/novosti/page-2.html` у документа.
- Два адреса не совпадают ни ключом, ни самим адресом: сохранение со столкновением отклоняется
  (`content.address_taken`).
- `cms import-evo` переносит `friendly_url_suffix`, `make_folders`, `use_alias_path`, `isfolder`,
  `alias_visible` и `searchable`; пустой алиас — id документа, weblink с целью `[~13~]` — ссылка на страницу,
  занятый адрес — предупреждение и алиас с id. На дампе gabriel.by все 2937 адресов карты сайта совпали.

### Списки (ADR 0064)

- `listing()` получил `filter(page)`, `order(a, b)` и явный номер порции `page`: отбор и порядок по полям
  страниц с обычным пейджером; кандидаты держатся в памяти до правки контента.

### Поиск

- В индекс идут только текстовые поля страниц; значение, равное умолчанию поля, пропускается; JSON (строки
  multiTV после переноса из Evo) — строками своих значений. В отрывке выдачи больше нет `{"fieldValue":…}`,
  значений выбора и флагов. Индекс перестраивается сам (формат 2).

### Связанная папка в медиатеке (ADR 0065)

- `cms media link <папка> --into <приставка>` — папка на диске сервера в медиатеке без байтов в базе: в
  `media_files` только строки (путь, хэш, тип, размер, размеры, описание), отдача — с диска через sendfile с
  Range, ETag и `immutable` по `?v=`. Повтор сверяет папку по размеру и времени изменения (хэш — только у
  изменённых), описания оставшихся файлов сохраняются; без папки — сверка всех связанных. `--dry-run`,
  `media.json`, `cms media unlink`. Путь к папке внутри каталога базы записывается от него.
- Пути медиатеки файлов папки — по правилу (транслит, остальное — дефисы, `-2` при совпадении); `media()`,
  `image()`, `/media/…` и «где используется» принимают и исходный путь `assets/images/4a_(5).jpg`.
- `--serve-original` — старые адреса `/<приставка>/<путь на диске>` отдаются как есть, раньше страниц и правил
  переадресации; выход из папки (`..`, `%2F`, ссылки наружу) — 404.
- Варианты картинок папки — в кэше медиатеки, не в базе; пропавший вариант отвечает 307 на оригинал и делается
  заново. Предела 25 МиБ у файлов папки нет.
- Менеджер: метка «в папке», фильтр по происхождению, превью из варианта 480; удалить и заменить такой файл
  нельзя (`media.linked_file`), описание — можно. Экран копий, `cms backup` и `cms info` говорят, что связанные
  папки в копию базы не входят. Диагностика: `media.linked_missing`, ссылки на исходные адреса — не битые.
- Транслитерация — общая (`shared/kernel/translit.ts`); белорусская `ў` теперь `u` и в алиасах страниц.

### Плавные переходы между страницами (ADR 0066)

- Настройка сайта `viewTransitions` (по умолчанию выключена): «Настройки» → «Сайт». Включённая — каждая страница,
  нарисованная шаблоном (и страница 404 сайта), получает в head
  `@media (prefers-reduced-motion: no-preference){@view-transition{navigation:auto}}`: переходы между
  документами в Chrome и Edge 126+, Safari 18.2+, остальные браузеры открывают страницы как обычно. Страницы-файлы
  и менеджер правила не получают; своё `@view-transition` шаблона важнее. Менять её может и агент
  (`update_settings`).

### Плагин отвечает сам и работает по расписанию (ADR 0067)

- Хук `handle(request, context)` — свой `Response` на запрос, на который сайт не ответил: после служебных
  адресов, файлов связанных папок, страниц, правил переадресации и прежних адресов, перед `notFound` и
  страницей 404. Любой метод: POST, PUT, OPTIONS (preflight CORS) приходят к плагинам сразу, без ответа — 405,
  как раньше. Первый ответ по порядку имён плагинов; исключение или 5 секунд без ответа — сбой
  `extensions.plugin_failed`, запрос идёт дальше. Ответ — мимо кэша страниц и хука `render`. Тело запроса — до
  64 КБ, больше — 413.
- Контекст плагина: `site()` (настройки и `custom`), `setCustom(key, value)` — своя настройка с проверками
  менеджера и сбросом кэша страниц (то же значение — ничего), `submit(form, values, options)` — заявка формы без
  печати и задачи защиты, с правилами полей, фильтром спама, уведомлением, письмом, вебхуком и целью
  (`forms.submitTrusted`), `log()`, `signal`.
- `schedule: { every: '12h', run(context) }` — задание по расписанию у `cms serve`: первый запуск через 5 секунд
  после старта, один запуск за раз, правка или выключение плагина заменяет задание, сбой —
  `extensions.schedule_failed`. CLI расписаний не запускает.

### Папка-сайт (ADR 0068)

- `cms media link <папка> --into razbor --static` — статический сайт (сборка Astro, старый лендинг) по
  `/razbor/…`: `index.html` у каталога, 301 на адрес со слэшем, своя `404.html` или страница 404 сайта; файлы
  ищутся на диске на каждый запрос, строк в медиатеке нет. ETag, `immutable` у `_astro/…`, `no-cache` у
  остального, br/gzip для текста, Range для видео; выход из папки, скрытое и чужие типы — 404. Сменить вид
  связанной папки нельзя — только через `unlink`. `cms info`, `cms backup` и экран копий говорят, что в копию
  базы она не входит.

### Основа картинки — одна на оригинал (ADR 0069)

- Новая картинка JPEG, PNG или WebP с основой другой (`taxi.webp` рядом с `taxi.jpg`) больше не получает её
  варианты размеров и не показывает старое изображение: запись отклоняется (`media.stem_taken`) с именем того
  файла — назовите иначе или замените. Замена тем же путём — как была.
- `image()` берёт варианты только у JPEG, PNG и WebP: SVG и GIF с той же основой остаются без чужого srcset.
- `cms media push`: две картинки папки с одной основой — нарушение правил папки. Замена формата в папке
  (`photo.jpg` → `photo.webp`) с `--prune` убирает прежнюю картинку с вариантами до записи новой, сервер режет
  варианты заново; без `--prune` или если прежнюю держат страницы — отказ с причиной. `--prune` убирает и варианты
  без своей картинки.
- `cms import-wp`: картинки с одной основой получают разные пути (`photo-2.png`).

## [0.1.5] — 2026-11-06

### Менеджер

- Навигация в шапке перестроена: ежедневные разделы остаются подписями слева и переливаются в меню
  «Ещё», когда не влезают; «Настройки» и «Помощь» — значками справа; «Предложения» — значок со
  счётчиком открытых наборов правок. На узком экране — значки, как и было.
- Точка «не сохранено» на кнопке «Сохранить» теперь видна (была акцент-на-акценте).
- Длинные адреса и заголовки в таблице обзора — с многоточием, а не жёстким срезом.

### Безопасность

- Повтор доставок (`resend`) и вебхуков заявок — только администратору, не всякому, кто читает заявки.
- Ссылку предпросмотра отзывает её создатель; чужую по id не погасить.
- У ссылок с `target` санитайзер навязывает `rel="noopener noreferrer"`.
- Адреса, которые сервер зовёт по настройке (ИИ-эндпоинт, хранилище копий, лента релизов), нельзя навести
  на облачную метадату и link-local; по http ходят только на эту машину; инсталлер перепроверяет адрес
  после переадресации. Петля и своя сеть (LAN) остаются — это нужно для self-hosting.
- Добавлен `SECURITY.md` с каналом приватного раскрытия.

### Промо-сайт

- Ролик пересобран в тёмной теме на обоих языках: знак-колибри анимирован, глаз виден, значки окон — колибри.
- Скриншоты менеджера пересняты на перестроенной шапке; на первом экране — кикер «CMS» и ссылка «посмотреть скрипт» с проверкой SHA256.
- Карточка для соцсетей (OG) перерисована на новой шапке.
