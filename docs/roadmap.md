- [x] Дерево страниц: алиасы с транслитерацией, пути, публикация, канонические URL, 404.

- [x] Кэш страниц в памяти со сбросом по событиям.

- [x] SPA менеджера на SvelteKit 3 (`adapter-static`), встроенное в бинарник (`scripts/build.ts`).
- [x] Дерево страниц, редактор страницы, редактор элементов на CodeMirror с ошибками компиляции,
  предпросмотр, поля, настройки, пользователи.
- [x] Контент из блоков: визуальный текст и компоненты сайта с формой по сигнатуре, поле `image` с

- [x] Оформление: меню сверху, как в Evo, блоки и вкладки MODX 3, акцент на выбор пользователя — остальные

- [x] Ссылки на страницы `[~id~]` в контенте: адрес подставляет рендер, переименование их не ломает;
  в редакторе ссылку выбирают по названию страницы.
- [x] Менеджер на сайтах в тысячи страниц: дети по индексу родителя, большое дерево свёрнуто до открытой
  страницы, JSON API сжимается (дерево 3000 страниц — 23 КБ вместо 680 КБ).

## M3 — Скорость ✅

- [x] Кэш страниц и сжатых вариантов с бюджетом в байтах (64 и 32 МБ), а не в штуках: обход сайта больше
  тысячи страниц не вымывает кэш; вытеснение «второй шанс» — попадание ничего не перестраивает.
- [x] Горячий путь без лишней работы: включённые плагины в памяти, а не запрос к базе на каждый ответ,
  ETag страницы из кэша считается один раз, cookie и query разбираются по требованию, значения полей
  читаются раз на страницу. На 3000 страниц: попадание в кэш — 0,23 мс (p50), холодный рендер — ~0,5 мс
  процессора на страницу.
- [x] Статика менеджера отдаётся сжатой (brotli, один раз на файл), CodeMirror грузится только в режиме
  HTML: открыть редактор страницы — 121 КБ вместо мегабайта.
- [x] Некэшируемые регионы `<Uncached>`: кэшированная страница плюс части, которые рендерятся на каждом
  запросе (как `[!…!]`).
- [x] Точная инвалидация кэша по тегам «страница → ветка → дети → элементы».
- [x] ETag/304, сжатие br/gzip с запоминанием по ETag, `x-cache`.
- [x] Ассеты менеджера: `_app/immutable/*` на год, `index.html` — со сверкой.
- [x] Медиа с долгим кэшированием (`?v=<хэш>`).
