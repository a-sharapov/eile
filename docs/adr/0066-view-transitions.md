# 0066. Плавные переходы между страницами одним переключателем

- Статус: принято
- Дата: 2026-11-08

## Контекст

Браузеры умеют плавно сменять одну страницу сайта другой без единой строки JS — View Transitions между
документами (Chrome и Edge 126+, Safari 18.2+). Для этого обе страницы должны нести правило CSS
`@view-transition { navigation: auto; }`. Владелец сайта хочет включить это, не правя шаблоны, а у сайта,
перенесённого из Evo, их десятки.

## Решение

**Настройка сайта `viewTransitions`, по умолчанию выключена.** Она хранится, как остальные (`site_settings`, строка
на ключ), проверяется в `changeSettings` (не `true`/`false` — `site.invalid_view_transitions`) и стоит флажком в
менеджере: «Настройки» → «Сайт», с подсказкой про браузеры. Это только вид переходов: адреса, выдача поисковикам и
ссылки в письмах от неё не зависят, поэтому её меняют и ключ API, и агент — `update_settings` получил поле
`viewTransitions` (в отличие от `_HUMAN_SETTINGS`, ADR 0063).

**Правило ставит рендер, как SEO-шапку.** Когда настройка включена, head каждой страницы, нарисованной шаблоном,
получает в конце:

```html
<style>@media (prefers-reduced-motion: no-preference){@view-transition{navigation:auto}}</style>
```

- В браузере без поддержки правило пропускается, страницы открываются как обычно. При «уменьшить движение» в
  системе переход не играет.
- Страница 404 сайта рисуется шаблоном и тоже его получает: переход на неё и с неё — часть сайта. Голый ответ
  404 без страницы 404, страницы-файлы (CSS, XML, ленты, ADR 0017), Markdown-версии, менеджер и служебные адреса —
  нет.
- Своё правило важнее: если в head вида или в стилях нарисованных компонентов уже есть `@view-transition`,
  второе не добавляется — шаблон может задать свои типы переходов.
- Правило — часть HTML первой фазы и лежит в кэше страниц. Смена настройки — событие `site.settings_changed`,
  оно и так сбрасывает весь кэш страниц.

**Встроенный `<style>`, а не файл.** Политика страниц сайта — `frame-ancestors 'self'` (страница-файл — своя, но
она правила не получает), стили она не ограничивает. Файл по образцу ADR 0047 стоил бы запроса ради 90 байт и
пришёл бы позже первой отрисовки: переход на первой же навигации мог бы не сработать. Если владелец ставит перед
сайтом свой CSP без `'unsafe-inline'` для стилей, он и так ломает стили островов и `css="injected"`.

## Последствия

- Переходы включаются одним флажком на всём сайте; шаблонам правило не нужно (памятка `cms-views`).
- В каждой странице сайта при включённой настройке +90 байт head.
- API: `SiteSettings.viewTransitions`, `viewTransitionHead(enabled, own)` в `delivery/domain/document.ts`.
- Тесты — `tests/view-transitions.test.ts`.
