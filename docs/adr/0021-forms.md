# 0021. Формы как в eForm: HTML5-разметка, тег `[#Form:имя]`, заявки

- Статус: принято
- Дата: 2026-10-30

## Контекст

Почти каждому сайту нужны формы: обратный звонок, заявка, вопрос. В Evo их делают двумя способами.

- **eForm.** Форма — обычный HTML-чанк, правило поля пишется рядом с ним атрибутом, отчёт и «спасибо» — свои
  чанки.
- **FormLister.** Правила — массивы в вызове сниппета, плюс контроллеры. Защита от повтора `protectSubmit` и
  лимит `submitLimit` держатся на сессии PHP (`assets/snippets/FormLister/lib/SubmitProtection.php`).

Владелец сайта выбрал идеологию eForm и хочет визуальный редактор форм. Заявки должны храниться в базе,
приходить менеджерам (конверт в шапке, мини-дашборд) и уходить в Telegram и на почту (ADR 0020).

## Решение

**Форма — HTML5-разметка.** Правила поля — его атрибуты: `required`, `type` (email, tel, url, number, date…),
`pattern`, `min`/`max`/`step`, `minlength`/`maxlength`, варианты `<option>` и группы переключателей.

- Подпись поля — `data-label` у обёртки `[data-field]`, иначе `<label for>`, `aria-label`, `placeholder`.
- Свой текст ошибки — `data-message`; скрытое поле с `data-source` берёт значение из источника.
- Сервер читает разметку `HTMLRewriter` (синхронно, на строке) и проверяет заявку по тем же правилам, что и
  браузер. `pattern` компилируется с флагом `v`, как в HTML; неверный шаблон не проверяется — так же поступает
  браузер.
- Сущности в атрибутах `HTMLRewriter` отдаёт сырыми: их раскрываем сами, а при записи значений экранируем `&`
  и `<`.
- Ничего, кроме полей из разметки, в заявку не попадает.

**Редактор — блоками, как текст страницы.**
- Поле — блок с формой параметров; текст и неполевая разметка — текстовые блоки.
- Нетронутое поле сохраняется как было, правленое — в каноническом виде; ручная вёрстка не теряется.
- Разбор в менеджере — DOM браузера, сборка — чистая функция. Совпадение сборки с разбором сервера проверяет
  `tests/form-blocks.test.ts`.
- Справа — предпросмотр: сервер рисует несохранённую форму в песочнице.

**Вставка.**
- В тексте — тег модуля `[#Форма:имя]`: `[#Form:callback]`. Форма — данные, а не компонент, поэтому у неё свой
  синтаксис, общий для будущих модулей. В редакторе контента это блок «Форма» с выбором из списка; разбор
  менеджера и сайта совпадает (`tests/content-blocks.test.ts`).
- В шаблоне — `$core/Form`.
- Тег становится регионом вида `module` и рисуется на каждом запросе: свежая печать, метки UTM, Referer, флеш.
  Страница вокруг остаётся в кэше, события форм кэш не сбрасывают.
- Ссылки `[~id~]` внутри формы (политика в согласии) раскрываются в адрес страницы.

**Приём: `POST /_cms/forms/<имя>`** — только с того же сайта (`Origin`, `Sec-Fetch-Site`), тело не больше
64 КБ.
- **Без JS — Post/Redirect/Get.** Успех — 303 на страницу «Спасибо» или обратно с `?sent=имя`, F5 не отправит
  форму второй раз. Ошибка — 303 обратно и флеш-cookie (HttpOnly, две минуты): форма покажет введённое и
  ошибки у полей.
- **С JS** — скрипт улучшения (обычный JS в бинарнике, `/_cms/forms/enhance.<хэш>.js`):
  - отправляет JSON без перезагрузки и показывает ошибки у полей;
  - устаревшую печать молча меняет на свежую и отправляет снова;
  - хранит черновик в `localStorage` и стирает его только после успеха;
  - запоминает метки UTM первого касания;
  - шлёт событие `cms:form-sent`.

**Защита без капчи.**

| Средство           | Как работает                                                                                                            |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| Ловушка            | Невидимое поле; заполнено — успех без записи                                                                            |
| Печать             | `Bun.CSRF` с `sessionId` = форма и момент показа; срок — сутки, повтор той же печатью — тот же успех без второй записи  |
| Минимальное время  | Быстрее `minSeconds` (по умолчанию 3) — «подождите»                                                                     |
| Лимит              | Не больше пяти заявок с адреса за 10 минут на форму, окно фиксированное — без вечной блокировки                         |
| Повтор             | Та же заявка за 3 минуты — тот же успех                                                                                 |
| Спам по содержанию | Ссылки (если форма их не ждёт) и разметка. Заявка сохраняется со статусом «спам» без уведомления — ошибку фильтра видно |
| Скрытые поля       | Значения страницы, сайта и времени сервер подставляет сам — подменить их нельзя                                         |

**Заявка** — снимок значений с ключами и подписями (правка формы не ломает старые заявки).
- Также хранятся страница, Referer, метки UTM, IP (владелец решил хранить), браузер, статус («новая», «в
  работе», «готово», «спам») и заметка.
- Первое открытие менеджером делает её прочитанной.
- Удаляется по сроку формы, по умолчанию через 30 дней (152-ФЗ); заявки удалённых форм — через 30 дней.
- Уведомление уходит через `notify` в каналы формы или по маршруту из настроек: тема с `{form}` и `{имя поля}`,
  ответ на письмо — почте посетителя, ссылка — в карточку заявки.

**Права.** Формы собирает администратор (`forms.edit`), заявки разбирают все менеджеры (`inbox.read`).

## Последствия

- Конверт в шапке опрашивает сводку раз в 30 секунд, пока вкладка видна.
- Секрет печатей — таблица этого сервера, в копию сайта не попадает; формы и заявки — попадают.
- Плагины могут подписаться на `forms.submission_received` — например, чтобы передать заявку в CRM.
- Файлы в формах, пошаговые формы и условные поля — пока нет.
