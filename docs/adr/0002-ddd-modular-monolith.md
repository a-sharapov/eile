# 0002. DDD: модульный монолит, гексагональные контексты, синхронные порты

- Статус: принято
- Дата: 2026-10-29

## Контекст

Ядро Evo — один класс на 7000 строк, где рендер, кэш, URL, события и доступ к базе перемешаны. CMS
должен расти (поля, менеджер, плагины, острова), не превращаясь в такой же клубок.

## Решение

1. **Модульный монолит.** Ограниченные контексты (`content`, `design`, `site`, `delivery`, дальше
   `manager`, `identity`, `extensions`, `media`) — это папки в одном процессе. Не микросервисы.
2. **Гексагональная структура контекста.** Слои `domain` → `application` → `infrastructure`/`interface`.
   Домен и сценарии — чистый TS без пакетов.
3. **Публичный API через `index.ts`.** Чужой контекст видит только его. Связывает контексты корень
   композиции `src/app.ts`.
4. **Единый язык** — [glossary.md](../glossary.md). Имена в коде совпадают с терминами.
5. **Синхронные порты.** Репозитории и модели чтения синхронны, потому что SQLite в процессе синхронный.
6. **Доменные события и синхронная шина в процессе.** Переход агрегата возвращает события, сценарий
   публикует их после сохранения.
7. **Правила проверяются автоматически** — `tests/architecture.test.ts`.

## Тактические шаблоны

- Агрегат: неизменяемый `type`, переходы — чистые функции, которые возвращают новое состояние и события
  (`Changed`). Подробно — [ADR 0006](0006-functional-style.md).
- Объект-значение: branded-тип плюс функция `parse…()`, которая отказывает через `fail()`.
- Код ошибки — стабильная строка `context.reason`, адаптеры превращают её в HTTP-ответы.
- Модель чтения (`PublishedContent`) отделена от репозитория агрегата (CQRS-lite) и возвращает DTO.
- Порт объявляет тот, кому он нужен (`delivery/application/ports.ts`), поставщик соответствует ему
  структурно.

## Последствия

- Сначала больше файлов, зато у каждого изменения понятное место.
- Нельзя «быстро» сходить в чужую таблицу. Нужно расширить публичный API контекста.
- Асинхронность видна в типах и встречается только там, где она реальна (загрузка модулей вида, HTTP).
