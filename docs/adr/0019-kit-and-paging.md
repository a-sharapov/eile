# 0019. Набор компонентов и постраничные списки с ЧПУ

- Статус: принято
- Дата: 2026-10-30

## Контекст

Почти любому сайту нужны одни и те же части: меню на несколько уровней, хлебные крошки, лента постов с
пейджером, окна. В Evo их дают поставляемые сниппеты: DLMenu, DLCrumbs, DocLister с `paginate`. Логика в
сниппете, вид — в чанках-шаблонах, которые правит верстальщик.

DocLister делит список на порции через `?page=N` (с префиксом `id_page`, если списков несколько). При
`page` ≤ 1 или больше числа порций он перенаправляет на адрес без параметра. ЧПУ для порций делается
своим `makePaginateUrl` (`assets/snippets/DocLister/core/extender/paginate.extender.inc`, `getUrl`,
`buildUrl`). У CMS ключ кэша — путь без query, так что `?page=2` отдал бы первую порцию. Владелец
сайта хочет ЧПУ: `/blog/page-2`.

## Решение

**Логика — в `$core`, вид — в компонентах набора.**

- `current()` — страница, которую рендерим. `ancestors(id)` — предки от корня, для крошек и активной
  ветки меню; как и ссылка `[~id~]`, зависит от ветки. `listing(parent, { perPage, sort, depth,
  includeHidden, paged })` — порция детей или потомков: `{ items, number, pages, total, url(n),
  pager(around) }`. Скрытые из меню по умолчанию в списке: посты блога в меню не нужны.
- Список считает SQLite (`content.published.list`): потомки до глубины `depth` берутся из индекса дерева
  в памяти, сортировка (`published`, `created`, `title`, `menu`) и порция — запросом. Глубина и размер
  порции ограничены: параметр компонента не развернёт весь сайт.

**Хвост адреса.** `/blog/page-2` — страница `/blog` с номером порции 2. Слово `page` — настройка сайта
(`pagingSegment`).

1. Сначала ищется страница по полному пути: настоящая страница с алиасом `page-2` важнее порции родителя.
2. Нет страницы — отрезаем `<слово>-N`. Номер без ведущих нулей и не длиннее шести цифр.
3. Порция 2 и дальше открывается, только если первый постраничный список страницы прочитал номер и порций
   хватает. Иначе 404, а не пустая страница: у страницы без списка нет дублей `/o-nas/page-7`.
4. `/blog/page-1` — 301 на `/blog`, как редирект DocLister. Старый адрес порции (после переименования
   раздела) ведёт 301 на ту же порцию по новому адресу.

Ключ кэша — полный путь, так что порции кэшируются как обычные страницы. Рост кэша ограничен числом
настоящих порций: всё за пределами — 404, а 404 не кэшируется. Список записывает теги `children:` всех
уровней, которые читает: новый пост сбрасывает все порции.

**Находимость порций.** canonical — на саму порцию, как советует Google; настройка `pagingCanonical:
'first'` ставит его на первую. К `<title>`, описанию и `og:title` добавляется «— страница N» на языке
страницы; перевод сайта `pagingTitle` с `{n}` заменяет встроенный текст. `<link rel="prev">` и
`rel="next"` — как `paginationMeta` у DocLister. В sitemap.xml и llms.txt только первая порция, Markdown-
версия — у неё одной. В JSON-LD BreadcrumbList порция — после самой страницы.

**Набор компонентов** лежит в бинарнике (`src/kit/`) и ставится в элементы сайта из менеджера («Элементы →
Набор компонентов»). Дальше компонент правится как свой. Повторная установка заменяет правленый на сайте
исходник только по явной просьбе; зависимости, которые уже есть, не трогает.

| Компонент                | Что делает                                                                                                                                                                                                                             | JS                                                                                                                                   |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `Menu`                   | Уровни рекурсивным `{#snippet}`, активная ветка по дереву, а не по началу адреса. Подменю по наведению и с клавиатуры (`:hover`, `:focus-within`, закрытие с задержкой). Без мыши или на узком экране — кнопка и панель на Popover API | остров `MenuKeys` только при подменю: Esc закрывает подменю, открытое наведением                                                     |
| `Breadcrumbs`            | `<nav><ol>`, текущая — `aria-current`, разделитель читалка не произносит; JSON-LD добавляет сайт сам                                                                                                                                   | нет                                                                                                                                  |
| `PostList`, `Pagination` | Карточка с одной ссылкой на всю площадь, `<time datetime>`, картинка из поля или для соцсетей; пейджер ссылками с пропусками                                                                                                           | нет                                                                                                                                  |
| `PostMeta`               | Дата и время чтения поста                                                                                                                                                                                                              | нет                                                                                                                                  |
| `Modal`, `ModalButton`   | `<dialog>` с `commandfor`/`command` и `closedby="any"`: открытие, Esc, фокус и подложка без JS; страница под окном не прокручивается (`html:has(dialog:modal)`)                                                                        | остров `ModalLinks`: ссылки `#адрес`, окно из адреса при загрузке, замена `commandfor` и `closedby` там, где браузер их ещё не знает |

Компоненты набора не объявляют параметр `page`, который `<Content>` передаёт всем: текущую страницу они
берут из `current()`. Цвета и скругления — переменные `--t-accent`, `--t-text`, `--t-muted`,
`--t-surface`, `--t-border`, `--t-hover`, `--t-radius` с умолчаниями: сайт задаёт их один раз в шаблоне.

## Последствия

- Демо-сайт собран из набора и показывает ленту с порциями (`/blog/page-2`).
- Постраничный список на странице один — первый, прочитавший номер. Остальным — `paged: false`.
- Двухуровневое меню зависит от детей разделов: правка дочерней страницы сбрасывает страницы с таким меню.
  Это честная зависимость: в меню её заголовок.
- `$props.id()` выводит маркер `<!--$s1-->`; рендер убирает его вместе с остальными маркерами гидрации.
