# 0009. Переезд с Evo: импорт дампа MySQL

- Статус: принято
- Дата: 2026-10-29

## Контекст

Переносить сайты на CMS будут в основном с MODX Evo. Подключаться к MySQL из бинарника — лишняя
зависимость и лишняя настройка, а дамп `mysqldump` есть у любого сайта.

## Решение

`cms import-evo dump.sql --db site.db` разбирает дамп и переносит в пустую базу:

- **дерево** `site_content` с сохранением id: старые ссылки `[~5~]` ведут туда же. Weblink становится
  ссылкой, удалённый документ попадает в корзину, `pub_date` / `unpub_date` переходят в расписание;
- **чанки** становятся компонентами, а **шаблоны** — шаблонами Svelte:

  | Evo             | Svelte                                                       |
  | --------------- | ------------------------------------------------------------ |
  | `[*field*]`     | `{page.…}` (TV — `{page.fields.…}`, `content` — `<Content>`) |
  | `{{chunk}}`     | `<Chunk {page} />`                                           |
  | `[(site_name)]` | `{site.name}`                                                |
  | `[~id~]`        | `link(id)`                                                   |
  | `[+ph+]`        | props компонента                                             |

  Текст HTML идёт в `{@html "…"}`, поэтому фигурные скобки и `<script>` старых шаблонов не ломают Svelte;
- **ссылки `[~id~]` в контенте** остаются как есть: `<Content>` подставляет текущий адрес страницы при
  рендере, поэтому перенос и переименование их не ломают (раньше импорт заменял их путями);
- **TV** становятся полями (тип, варианты, `@INHERIT` → наследование, назначение на шаблоны), значения
  переносятся с проверкой по типу;
- **настройки**: `site_name`, `site_start`, `error_page`.

Сниппеты PHP не переносятся: их вызовы остаются HTML-комментариями `<!-- Evo snippet: … -->`, а список имён
попадает в отчёт — это работа разработчика. Ошибка одной записи не останавливает перенос, а попадает в
`warnings` отчёта.

Разбор дампа понимает `CREATE TABLE`, `INSERT`/`REPLACE` с колонками и без них, а также
`ALTER TABLE … ADD COLUMN … AFTER`, которыми достраивает схему установщик Evo.

## Проверка

Демо-сайт установщика Evolution CMS 1.4.37 (`install/setup.sql` + `setup.data.sql`) переносится без
предупреждений: 21 страница, 2 шаблона, 9 чанков. Все страницы отвечают 200.
