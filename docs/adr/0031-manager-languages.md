# 0031. Языки менеджера: словари по языкам, выбор у пользователя, тексты сервера на языке запроса

- Статус: принято
- Дата: 2026-10-31

## Контекст

Менеджер был только на русском: строки лежали одним словарём в `manager/src/lib/i18n.ts`, часть — прямо в
коде (размеры файлов, подсказки для ИИ, заготовки форм), помощь — разметкой в одной странице. Часть строк
склеивалась с числами и именами («осталось дней:» + 30, «Опубликуется» + дата) и на другом языке не
читалась бы. Тексты «Диагностики» и письмо для сброса пароля собирал сервер — тоже по-русски. Нужны
английский и немецкий, дальше — другие языки без переделки.

## Решение

**Словари — по языку, ключи задаёт русский.**
- `manager/src/lib/locales/ru.ts` — образец: `messages` (строки интерфейса) и `errors` (коды `DomainError`
  сервера → понятные сообщения).
- `en.ts`, `de.ts` типизированы `Dictionary`: tsc не пропустит словарь без ключа или с лишним.
- `tests/manager-i18n.test.ts` сверяет порядок ключей, подстановки `{name}`, формы чисел и пустые
  переводы, а ещё ищет кириллицу в коде менеджера вне словарей — забытую строку.

**Строка — целиком, с подстановками.**
- `t(key, { n, when, title })` подставляет `{name}`; обрывков, к которым код клеит число или дату, больше
  нет.
- `tn(key, n)` выбирает форму числа по `Intl.PluralRules`: формы через `|`. У русского — `one|few|many`,
  у английского и немецкого — `one|other`. Одна форма годится для любого числа («{n} стр.»).
- `number()`, `moment()`, `ago()`, `fileSize()` форматируют по языку менеджера, `quoted()` ставит кавычки
  языка: «…», “…”, „…“.
- Помощь переводится целыми главами: `HelpRu.svelte`, `HelpEn.svelte`, `HelpDe.svelte` с общей разметкой
  и общими стилями `help.css`; оглавление и поиск — одни на все языки.

**Загружается один словарь.** `hooks.client.ts` в `init` подгружает словарь выбранного языка до первой
отрисовки. Другие языки — отдельными чанками.

**Язык выбирает пользователь.**
- До входа — язык из этого браузера (`localStorage`), иначе первый подходящий из `navigator.languages`,
  иначе английский.
- Выбор — на экране входа рядом со схемой и в меню профиля. Список, а не переключатель: языков станет
  больше.
- Язык хранится в оформлении пользователя: колонка `manager_appearance.language`, `null` — как просит
  браузер. Язык, выбранный на входе, после входа становится языком пользователя, как и схема.
- `PUT /appearance` принимает часть полей: язык меняется, не трогая цвета.

**Смена языка без перезагрузки.** Корневой макет оборачивает менеджер в `{#key}` по языку, и смена его
перерисовывает целиком. Поэтому `t()` вызывается только при отрисовке и в функциях, а не при загрузке
модуля; так уже было, и это стоит держать.

**Сервер собирает тексты на языке запроса.**
- Менеджер шлёт свой язык первым в `Accept-Language`; `managerLanguageOf()` из ядра понимает `en`, `de`,
  `ru`, остальное — английский.
- «Диагностика»: проверка получает язык (`Check.run(language)`), тексты встроенных проверок —
  `diagnostics/domain/texts.ts` и `src/server-checks.ts`. Отчёт кэшируется отдельно на каждый язык.
- Письмо для сброса пароля — на языке страницы, с которой его попросили: её человек только что читал.
- Заголовки CSV заявок — по `?lang=`: ссылку на файл браузер открывает без заголовков `fetch`.

**Уведомления и журнал сбоев.** Их сервер собирает без запроса менеджера, поэтому язык берётся не из
запроса.
- Язык уведомлений — в «Настройках → Уведомления» (`NotifySettings.language`). Не выбран — язык сайта,
  если менеджер его знает, иначе английский.
- Сбой (`Alert` в ядре) приходит с заголовком на каждом языке (`Localized`), подробности — так же или
  одной строкой для всех: стек и текст ошибки не переводятся. Тексты пишет тот контекст, где случился сбой.
- Журнал хранит все языки (`notify_incidents.texts`) и показывает сбой на языке того, кто его читает.
  Уведомление уходит на языке уведомлений; язык сохраняется в нём, и подпись важности
  («Критично», «Kritisch») ставит канал.
- В уведомлении о заявке на языке уведомлений только подписи Eile («Страница», «Открыть заявку»).
  Тема и поля — содержимое формы, они остаются как на сайте.
- Записи журнала и уведомления в очереди со старых версий остаются по-русски.

**Что не переводим.**
- Содержимое, которое владелец уже написал: страницы, свои формы, свои компоненты. Каркасы `cms new`,
  набор компонентов и тексты форм на сайте с 2026-10-31 есть на английском и выбираются по языку сайта
  ([ADR 0022](0022-scaffolds.md)), но это язык сайта, а не менеджера.
- Системный промпт ИИ — английский, один для всех: по-английски модели точнее всего следуют указаниям.
  Факты о месте правки идут на языке менеджера, отвечает ИИ на языке сайта, как и раньше.

## Последствия

- Новый язык: словарь `locales/xx.ts`, глава помощи `HelpXx.svelte`, строка в `LANGUAGES` менеджера и в
  `MANAGER_LANGUAGES` ядра, тексты в таблицах сервера (диагностика, письмо, CSV). tsc укажет все места.
- Новая строка интерфейса — сразу во всех словарях; иначе не соберётся.
- Немецкие подписи длиннее примерно на треть: узкие места (кнопки, вкладки, шапка) проверяются на `de`.
