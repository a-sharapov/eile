# 0016. ИИ-помощник: палочка у полей и системный промпт на сервере

- Статус: принято
- Дата: 2026-10-30

## Контекст

Владелец сайта хочет подключить ИИ и заполнять любое поле по короткому запросу: заголовки, описания,
текст страницы, а администратору — код шаблонов, компонентов и плагинов. Модель должна понимать, где
она работает: какой сайт, какое поле, какие у него ограничения и правила.

## Решение

- **Контекст `assistant`.** Подключение — адрес OpenAI-совместимого API (DeepSeek, OpenAI, OpenRouter,
  локальные модели), модель, ключ и «указания для ИИ». Одна строка `assistant_connection`.
- **Ключ — только на сервере.** API отдаёт подключение без ключа; пустой ключ в форме оставляет прежний.
  Таблица подключения, как и сеансы входа, — свойство сервера: в копии сайта не попадает и при
  восстановлении остаётся своей (ADR 0015).
- **Промпт собирает сервер** (`buildPrompt`): сайт и язык, поле (подпись, подсказка, длина, шаблон
  значения), место (страница, шаблон и факты о нём), правила вида и указания владельца. Для шаблонов,
  компонентов и плагинов — правила CMS (Svelte 5 runes, `$props`, `$components/*`, `$core`,
  JSDoc-подписи параметров) и требование вернуть файл целиком. Ответ чистится: без обёртки ```, лишних
  кавычек, у строки — без переносов и в пределах длины.
- **Права.** Генерировать тексты может тот, кто правит страницы; код — только тот, кто правит элементы.
- **Аудит безопасности.** Ключ остаётся прежним без нового значения, только если хост API тот же: иначе
  его вводят заново, и сменой адреса ключ не увести. Переадресации клиент не выполняет. Подробность
  сбоя стороннего сервиса видит администратор, остальным — `assistant.unavailable`. У каждого не больше
  двух генераций разом и 120 в час (`assistant.busy`).
- **Менеджер.** Палочки ставит `aiWands()` у каждого текстового поля с подписью и у ячеек таблиц (без
  поиска, паролей, адресов и полей в окнах; `data-ai="off"` отключает); Alt+I в поле — то же с
  клавиатуры, палочка от читалки скрыта, клавиша — в описании поля. В тексте страницы и редакторе кода
  — своя кнопка. Окошко: запрос → предпросмотр → «Вставить»; в полях — «Вернуть» в уведомлении, в
  тексте и коде — Ctrl+Z. HTML ответа для текста страницы проходит схему редактора.

## Следствия

- Тесты подменяют модель локальным сервером в формате OpenAI; настоящий ключ в репозитории не живёт.
- Запросы идут от сервера: модель видит адрес сервера, а не браузера редактора.
- Картинки модель не видит: описание картинки она пишет по имени файла и страницам, где та стоит.
