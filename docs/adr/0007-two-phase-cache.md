# 0007. Двухфазный рендер и кэш с тегами

- Статус: принято
- Дата: 2026-10-29

## Контекст

Скорость Evo держится на двух вещах: готовый HTML лежит в кэше, а некэшируемые сниппеты `[!…!]`
дорисовываются на каждом запросе. Но при любом сохранении Evo сбрасывает весь кэш. CMS должна взять
сильную сторону и исправить слабую.

## Решение

**Две фазы.**
1. Шаблон рендерится целиком. Компонент `<Uncached name="Cart" props={…} />` из `$core/Uncached` вместо
   себя ставит маркер `<!--cms:region:N-->` и запоминает имя и props. Props снимаются через JSON и
   поэтому должны быть сериализуемыми.
2. На каждом запросе регионы рендерятся заново и встают на места маркеров. Их стили дописываются в `<head>`.
   Если в регионе ошибка, на его месте пусто, а страница работает.

В кэш идёт результат первой фазы. У страницы без регионов кэшируется готовый документ.

**Теги.** Во время рендера область (`RenderScope`) записывает, что прочитано:

| Тег                     | Откуда                                          |
| ----------------------- | ----------------------------------------------- |
| `page:<id>`             | сама страница, `page(id)`, `link(id)`           |
| `branch:<id>`           | каждый предок страницы: наследуемые поля и путь |
| `children:<id \| root>` | `children(parentId)`                            |
| `element:<kind>/<name>` | шаблон и все компоненты его графа импортов      |
| `request`               | `request()` в первой фазе                       |

Событие страницы сбрасывает `page:`, `branch:` и `children:` родителя (при перемещении — и прежнего
родителя). Правка элемента сбрасывает `element:`. Настройки сайта и описания полей сбрасывают всё.

**Защита от утечки запроса.** Если первая фаза прочитала `request()`, страница в кэш не идёт (`x-cache:
bypass`). Данные запроса читаются только внутри `Uncached`.

**HTTP.** ETag — хэш готового документа, на него отвечаем 304. Сжатие br (качество 9) или gzip выбирается
по `Accept-Encoding` и запоминается по ETag. `cache-control: no-cache` заставляет браузер сверяться с
сервером. Заголовок `x-cache: hit | miss | bypass` показывает, откуда страница.

## Последствия

- Правка одной страницы не сбрасывает весь сайт. Меню, которое читает `children:root`, сбрасывается только
  при изменении страниц верхнего уровня.
- SSR Svelte синхронный, поэтому одной текущей области на процесс хватает: два рендера не перемешаются.
- Регион внутри региона не поддерживается.
- 404 и редиректы не кэшируются.
