# 0013. Переводы и свои настройки: `{i18n.key}` и `[@key]`

- Статус: принято
- Дата: 2026-10-30

## Контекст

Многоязычный сайт на Evo собирают из веток по языкам и словарей сниппетов; общие для сайта значения
(телефон, адрес) пишут в системные настройки и выводят `[(setting)]`. Нужны оба механизма без плагинов,
но так, чтобы ими можно было не пользоваться: текст на любом языке пишется прямо в странице.

## Решение

- **Язык страницы** (`language`) пишется на ветку: страницы внутри наследуют его, у корня — язык сайта.
  Сайт хранит язык по умолчанию и список других языков. `<html lang>` — язык страницы.
- **Перевод** — ключ и текст на каждом языке сайта. `{i18n.key}` даёт текст на языке страницы, иначе
  на языке по умолчанию; нет ключа — ключ остаётся на странице как есть, чтобы пропуск было видно.
- **Своя настройка** — ключ и значение; `[@key]` подставляет значение везде.
- В тексте страницы ключи подставляются до разбора тегов контента, поэтому работают и в параметрах
  `[[Callout text="{i18n.hello}"]]`; в HTML значение экранируется.
- В шаблонах и компонентах переводы и свои настройки лежат в `site`: `{site.i18n.key}` и
  `{site.custom.key}` — обычные выражения Svelte, исходник ничем не переписывается (компоненту `site`
  отдаёт `site()` из `$core`, там же есть `t(key)` и `setting(key)`). Теги `{i18n.key}` и `[@key]` в
  разметке шаблона отклоняются при сохранении с подсказкой (`design.key_tags`): Svelte принял бы
  `{i18n.key}` за своё выражение. Скомпилированный вид от словаря не зависит — правка перевода
  сбрасывает только кэш страниц. _Изменено 2026-10-30: раньше теги в шаблонах переписывались в вызовы
  до компиляции; владелец предложил брать ключи из `site` и отключить для шаблонов особый тег._
- Ключ — идентификатор JS (`footerText`): `{i18n.footerText}` читается как обращение к свойству.
- **Пояснение** (дополнено 2026-11-03): у своей настройки есть строка для людей в менеджере — что это и
  где взять значение (`CustomSetting.note`, до 500 знаков). На сайт она не попадает; правка значения её не
  стирает ([ADR 0055](0055-kitchen-studio-scaffold.md)).
- **Несколько строк и словарь целиком** (дополнено 2026-11-05): значение перевода и своей настройки может
  быть в несколько строк — список хранят по пункту на строку, переводы строк приводятся к LF. `site.i18n` и
  `site.custom` перечисляются (`Object.keys`, `JSON.stringify`): ключи со значением на языке страницы
  ([ADR 0061](0061-translations-in-packages-and-for-agents.md)).

## Последствия

- В островах ключи запрещены: в браузере нет словарей, тексты передаются через props.
- Связь «эта страница — перевод той» (hreflang) — набор переводов, [ADR 0033](0033-page-translations.md).
