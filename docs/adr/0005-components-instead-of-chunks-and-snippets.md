# 0005. Компоненты вместо чанков и сниппетов, страницы вместо ресурсов

- Статус: принято
- Дата: 2026-10-29

## Контекст

В Evo чанк — HTML без логики, сниппет — PHP-код. CMS строит и то и другое на Svelte. Названия разрешено
менять в угоду здравому смыслу.

## Решение

| Evo                 | CMS                   | Почему                                                                                                                                                                                                                               |
| ------------------- | --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Чанк + сниппет      | **Компонент**         | Выражения в разметке Svelte — уже JS, так что граница «разметка или код» стирается и не служит ни технической, ни защитной границей. Кроме того, в Svelte 5 уже есть свои «сниппеты» (`{#snippet}`), и совпадение названий путало бы |
| Шаблон              | **Шаблон**            | Термин понятен, остаётся                                                                                                                                                                                                             |
| Элемент             | **Элемент**           | Общее имя шаблонов и компонентов, как в менеджере Evo                                                                                                                                                                                |
| Ресурс / документ   | **Страница**          | Так говорят пользователи, а «ресурс» перегружен (HTTP, Ash)                                                                                                                                                                          |
| TV                  | **Поле**              | Понятнее, и связка с шаблоном сохраняется                                                                                                                                                                                            |
| Системная настройка | **Настройка сайта**   | Контекст `site`                                                                                                                                                                                                                      |
| Плейсхолдер `[+x+]` | props компонента      | Механизм Svelte                                                                                                                                                                                                                      |
| `[~id~]`            | `link(id)` из `$core` | Обычная функция                                                                                                                                                                                                                      |

Компоненты подключаются обычным импортом: `import Menu from '$components/Menu'`. Данные компонент берёт из
`$core` синхронно прямо в `<script>`.

## Последствия

- Права на правку элементов — одни для шаблонов и компонентов: любой элемент исполняет код на сервере.
- Разделение «для верстальщика / для программиста» при необходимости делается категориями в менеджере, а не
  разными типами сущностей.
