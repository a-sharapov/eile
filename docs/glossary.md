# Единый язык

Термины, которыми говорим и пишем код. Если термин меняется, его меняют здесь, в коде и в документации разом.
«План» — понятие уже определено, но ещё не реализовано.

## content — дерево страниц

| Термин                 | Что это                                                                                                           | В коде                                                      | В Evo                                  |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- | -------------------------------------- |
| Страница               | Узел дерева сайта                                                                                                 | `Page` (агрегат)                                            | ресурс, документ (`site_content`)      |

| Путь                   | Алиасы предков и страницы: `/blog/first-post`                                                                     | `PageView.path`                                             | путь из алиасов (`use_alias_path`)     |
| Родитель               | Страница выше по дереву; `null` — верхний уровень                                                                 | `parentId`                                                  | `parent` (0 — корень)                  |
| Опубликована           | Видна посетителям                                                                                                 | `published`                                                 | `published`                            |
| Кэшируемая             | Готовый HTML можно хранить в кэше                                                                                 | `cacheable`                                                 | `cacheable`                            |
| Скрыта из меню         | Не попадает в `children()` по умолчанию                                                                           | `hiddenFromMenu`                                            | `hidemenu`                             |
| Порядок в меню         | Сортировка среди соседей                                                                                          | `menuIndex`                                                 | `menuindex`                            |
| Опубликованный контент | Модель чтения только опубликованных страниц                                                                       | `PublishedContent`, `PageView`                              | —                                      |
| Поле                   | Дополнительное типизированное поле (text, richtext, number, boolean, date, select, image), назначается на шаблоны | `Field`, `content.fields.save`                              | TV                                     |
| Значение поля          | Своё значение страницы; в шаблоне — `page.fields.<имя>`                                                           | `Page.fields`, `PageView.fields`                            | значение TV                            |
| Блок контента          | Часть контента в менеджере: текст или отдельно стоящий вызов компонента `[[Name prop="x"]]`                       | `Block`, `parseBlocks()` (менеджер)                         | вызов сниппета в контенте              |

| Показывать в поиске    | Страница видна поисковикам и ИИ; иначе noindex, её нет в sitemap.xml и llms.txt                                   | `searchable`                                                | `searchable`                           |
| Картинка для соцсетей  | Путь файла медиатеки для Open Graph; пусто — картинка сайта                                                       | `socialImage`                                               | —                                      |
| Старый адрес           | Прежний путь страницы после смены алиаса или переноса; ведёт на неё 301                                           | `content_old_paths`, `movedFrom`                            | плагины переадресации                  |
| Язык страницы          | Язык ветки: свой у страницы или у ближайшего предка, у корня — язык сайта                                         | `language`                                                  | контексты и ветки языков               |
| Набор переводов        | Исходная страница и её переводы на другие языки: перевод указывает на исходную; отсюда hreflang и переключатель   | `translationOf`, `published.translations`, `translations()` | связи Babel                            |
| Вид страницы           | `page` — обычная страница, `link` — ссылка с редиректом 301 на `linkTo`                                           | `PageKind`, `kind`                                          | `type`: document / reference (weblink) |

| Ссылка на страницу     | `[~5~]` в контенте: при рендере становится текущим адресом страницы, переименование её не ломает                  | `resolvePageLinks()`                                        | `[~5~]`                                |

| Заголовок в меню       | Для пунктов меню, если задан                                                                                      | `menuTitle`                                                 | `menutitle`                            |
| Описание               | Для `<meta name="description">`                                                                                   | `description`                                               | `description`                          |
| Анонс                  | Короткий текст для списков                                                                                        | `introText`                                                 | `introtext`                            |
| Расписание             | Момент отложенной публикации и снятия; применяется в начале запроса                                               | `publishAt`, `unpublishAt`, `content.schedule.runDue`       | `pub_date`, `unpub_date`               |
| Дата публикации        | Когда страница последний раз опубликована                                                                         | `publishedAt`                                               | `publishedon`                          |
| Корзина                | Страница в корзине скрывает всю свою ветку, её алиас свободен; `trash.empty` удаляет навсегда                     | `trashedAt`, `content.pages.trash`                          | `deleted`                              |
| Версия страницы        | Какой страница была до правки: текст, заголовки, адрес, шаблон и поля; правки одного человека за 10 минут — одна  | `Revision`, `content.revisions`                             | —                                      |
| Возврат к версии       | Страница снова такая, как в версии; нынешнее состояние уходит в историю новой версией                             | `content.revisions.restore`                                 | —                                      |
| Автор правки           | Кто правил: пользователь менеджера; без него — сам сайт: каркас, импорт, плагин                                   | `Author`                                                    | `editedby`                             |
| Момент                 | Время в ISO 8601 UTC                                                                                              | `Moment`                                                    | unix-время                             |
